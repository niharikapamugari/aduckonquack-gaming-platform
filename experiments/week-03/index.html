Lab Experiment 3: Internal, External, and Inline CSS

This page demonstrates the 3 distinct methods of applying CSS rules across Week 1 (Home, Login) and Week 2 (Registration) UI components:

1. External CSS Demo (external-style.css)

Home Page Card Styled via External CSS

The container border, card background, fonts, and button hover states are loaded from <link rel="stylesheet" href="external-style.css">.

2. Internal CSS Demo (<style> block)

Login Page Component Styled via Internal CSS

Rules for .internal-section, .internal-title, and glowing neon borders are authored in the document head inside <style>.

3. Inline CSS Demo (style attribute)

Student Registration Alert Styled via Inline CSS

This container directly uses HTML attribute style="background-color: #1f1245; border: 2px dashed #f59e0b; ..." to exhibit highest CSS specificity precedence over document-level styles.

Priority: Inline > Internal > External > Browser Default
